# R3.6.3 — блокеры

## P0

- 78 структурных кандидатов требуют подтверждения специалистом; 20 координат не разрешились в узел текущего adapter.
- 140 кандидатов ещё не преобразованы в конкретные `DocumentBinding`, `ConditionalDocumentRegion` и `RepeatingGroup` с проверкой пересечений.
- Две реальные версии остаются DRAFT. Это правильно для preflight, но варианты опубликованного продукта к ним не привязываются.
- Нет двух успешно сформированных контрольных DOCX; неизменность нетронутых OOXML-узлов и отсутствие красного текста после rendering не доказаны.
- 120 natural-language prompt fixtures не превращены в детерминированные typed fact fixtures; LLM использовать запрещено.

## Следующий безопасный шаг

Специалист подтверждает либо отклоняет кандидаты в `/templates`. После этого отдельный importer должен материализовать только подтверждённые операции, валидировать пересечения и fingerprint, выполнить draft-only test generation обоих вариантов, OOXML diff и ручную проверку Microsoft Word. До этого публикация запрещена.
