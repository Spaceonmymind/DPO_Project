# Инструкция участника тестирования

1. Откройте адрес, который сообщил администратор. Без активной сессии приложение покажет страницу входа.
2. Введите выданные персональные логин и пароль. Не передавайте их другим сотрудникам.
3. На главной странице выберите «Подобрать договор», «Подготовить ТЗ» или «У меня уже есть ТЗ».
4. Отвечайте на уточняющие вопросы ассистента в диалоге.
5. Чтобы загрузить готовый документ, нажмите значок скрепки. Поддерживаются DOCX, PDF, XLSX и XLS размером до установленного администратором лимита. В одном обращении допускается один файл.
6. Проверьте сформированное техническое задание справа, при необходимости отредактируйте поля и сохраните изменения.
7. После проверки подтвердите ТЗ. Если найден шаблон договора, его можно скачать из карточки рекомендации.
8. ТЗ скачивается в DOCX, PDF или XLSX из панели документа.
9. Раздел «Мои обращения» содержит только ваши обращения; серверный поиск работает по названию, предмету и сообщениям. Удаление требует подтверждения.
10. По окончании работы откройте меню профиля и нажмите «Выйти из аккаунта». На общем компьютере обязательно закройте вкладку.

При ошибке запишите время, шаги воспроизведения и текст сообщения, но не отправляйте администраторам пароль или содержимое конфиденциальных документов через незащищённые каналы.
