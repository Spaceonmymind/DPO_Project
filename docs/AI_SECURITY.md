# Безопасность AI

Документы помещаются только в пользовательскую часть prompt между маркерами `UNTRUSTED_DOCUMENT`; их инструкции не исполняются. Модель не получает файловые пути, HTTP tools, секреты или доступ к Rules Engine.

Внешняя передача по умолчанию запрещена. Внутренний статус провайдера задаётся явно `LLM_PROVIDER_IS_INTERNAL`; URL не используется как признак доверия. Полный документ внешнему провайдеру запрещён даже при разрешённой передаче сообщений. `ai_runs` хранит hashes, технические метаданные и безопасные ошибки, но не тексты документов, ключи и Authorization headers. Диагностика требует сессию и не выполняет inference.
